# MZ — revision two

The visual world follows the supplied MZ pair: orange bandanas, blue apparel, dark outlines, white gloves and expressive running poses. Paper, ink, orange and blue are used across the editorial scenes and optional game. VAP informed scale, layering and pacing in the earlier concept; this revision develops the approved MZ composition.

The sequence is Outside → The Crew → A Change of Scenery → Zoom Run → Your Rhythm → Next Run → Keep Zoomin’. The hero and navigation link directly to Play. Visitors can skip the game and find practical club information immediately.

The default page is a sequence of still poster-like compositions. The girl and boy appear together in the hero and finale, with separate SVG layers following a shared path through the hero and crew, disappearing before the middle scenes and returning in the footer. Decorative motion is an explicit opt-in; user-initiated gameplay owns an independent lifecycle.

Zoom Run turns the page’s typographic landscape into a road. Oversized background text, flat lane geometry, functional game sprites and a ten-bar HUD keep it connected to the surrounding design. No scroll locking, mandatory game completion, accounts, global leaderboard or external submissions are introduced.

The game aims for a forgiving first minute: one-button jumping, clear pickups, discrete one-bar damage and a recovery period. Difficulty increases gradually through speed, shorter spawn intervals and more hazard types. Water at full health remains useful through bonus points. Game-over provides another run and a link to the real club.

Mobile gets a taller track, larger visible runner, fewer simultaneous hazards, a capped road speed, wrapping HUD and persistent large Jump button. It does not depend on hover or horizontal scroll. Keyboard users retain native activation of Pause and Restart controls; Space jumps only while the game canvas has focus.

The separated vector source and eight-frame atlas preserve the actual supplied artwork. Future animation can replace the optional scene media or refine sprite timing independently of the page layout and gameplay rules.
